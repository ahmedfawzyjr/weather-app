# Weather App

[![API: OpenWeather](https://img.shields.io/badge/API-OpenWeatherAPI-orange.svg)]()
[![Frontend: JavaScript](https://img.shields.io/badge/Frontend-JavaScript%20%7C%20CSS-blue.svg)]()

> A responsive weather forecast web application providing real-time weather metrics, 5-day forecasts, geolocation auto-lookup, and dynamic UI themes based on local climate conditions.

---

## ✨ Features

- **Current Weather Metrics**: Temperature, humidity, wind speed, pressure, and visibility.
- **Multi-City Search**: Fast location lookup with auto-complete capability.
- **Dynamic Backgrounds**: Visual changes matching rainy, sunny, cloudy, or snowy conditions.

```bash
git clone https://github.com/ahmedfawzyjr/weather-app.git
cd weather-app
npm start
```
